# Vulkan Requirements

## Component
`vulkan`

## Functional requirements
- V-FR-001: The component shall create supported graphics/compute contexts.
- V-FR-002: The component shall manage graphics resources.
- V-FR-003: The component shall submit supported workloads.
- V-FR-004: The component shall report device/context loss.

## Interface requirements
- V-IR-001: Use only approved upper/lower interfaces.
- V-IR-002: Hide vendor-specific implementation from consumers.

## Security requirements
- V-SR-001: Use approved security services and policies for protected operations.
- V-SR-002: Report security-relevant failures for audit.

## Reliability requirements
- V-RR-001: Provide defined behavior for device lost.
- V-RR-002: Provide defined behavior for resource allocation failure.
- V-RR-003: Provide defined behavior for unsupported feature.
