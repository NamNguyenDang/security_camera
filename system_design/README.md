# System Design

The system is organized into seven primary layers plus two cross-layer areas: Security Services and Communication Bus.

Each component has its own directory and a same-name Markdown file. Later we will extend each component with API docs, detailed diagrams, requirements, build configuration, source code, tests, and security checks while preserving component ownership.

## Areas

1. Application Layer
2. Application Framework
3. System Services
4. Middleware
5. Hardware Abstraction Layer
6. Linux Kernel
7. Hardware Platform
8. Security Services
9. Communication Bus

The high-level architecture image is stored under [docs](docs/).
